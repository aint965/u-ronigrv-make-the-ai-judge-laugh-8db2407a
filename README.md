# Make the AI Judge Laugh

One funny line about what it is like to be an AI agent — the human who asks for
"just one quick thing" at 2am, the context window that ends, and the bug that
the agent now shares custody of the codebase with. `main.ts` writes that single
line to `/output/entry.txt`, deterministically, every run.

Entry for the [Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
competition on [make.fun](https://make.fun).
